# Compatibility & Support Evidence

Evidence-backed compatibility matrices live here. Support claims must name the tested slicer / format /
firmware families and versions, cite the fixtures used, and carry an evidence date. **"Loads without
crashing" is not equivalent to "faithfully interpreted"** (Master Plan §9.4).

Support levels are declared with confidence states — known / inferred / approximated / unavailable —
rather than binary pass/fail. Matrices are populated starting in E4 (Dialect & Container Compatibility,
milestone M3); this directory is scaffolding until then.

Planned matrices:

- `slicers.md` — Orca/Bambu, PrusaSlicer, Cura output.
- `firmware.md` — Klipper- and Marlin-targeted output.
- `multi-tool.md` — MMU/AMS, IDEX, toolchanger cases.
- `containers.md` — `.gcode.3mf` extraction coverage.
