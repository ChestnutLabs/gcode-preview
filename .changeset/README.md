# Changesets (DD-008 D1/D2)

Release notes accumulate here as human-written changeset files, reviewed in the PR that makes the
change. All nine `@chestnutlabs/*` packages version in **lockstep** (a fixed group): any bump moves
the whole line.

- Behavior-changing PR → `npx changeset` → pick the bump (pre-1.0: minor may break — the change
  then also needs the `breaking-change` label + a migration note; patch = fixes) → commit the
  generated file with your PR. CI enforces presence for package-source changes.
- Docs/test/tooling-only PRs need no changeset.
- Release PRs ("Version Packages") are generated by the release workflow — never hand-edit
  versions or changelogs. Publication happens only from protected CI on a tag from `main`
  (see [`docs/reference/release-process.md`](../docs/reference/release-process.md)).
